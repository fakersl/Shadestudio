# shade·studio

**Uma cor. Oito tons. Mais possibilidades para criar.**

O Shade Studio nasceu de uma coisa simples: encontrar sombras que realmente combinem com a cor que estou usando em um design.

Às vezes, você já tem a cor perfeita, mas falta aquele tom mais escuro para uma borda, um detalhe, um contorno ou um degradê. Ficar ajustando cada cor manualmente dá trabalho, e nem sempre o resultado fica como você imaginava.

Foi por isso que criei o Shade Studio: uma ferramenta para explorar variações de uma cor, comparar tons e encontrar combinações que funcionem no seu projeto.

Seja para criar artes no Photoshop, trabalhar com ilustrações, montar paletas ou experimentar novas combinações, a ideia é a mesma: **menos tempo procurando cores e mais tempo criando.**

## O que você pode fazer

- **Gerar 8 tons de sombra** a partir de uma cor, do mais suave ao mais profundo.
- **Escolher qualquer cor** usando o seletor visual ou inserindo seu código diretamente.
- **Ajustar a intensidade** para criar variações mais discretas ou mais contrastantes.
- **Explorar combinações** e comparar os tons antes de usá-los no seu design.
- **Copiar as cores** individualmente ou exportar a escala completa.
- **Visualizar as cores em uma interface de exemplo** para ter uma ideia de como funcionam juntas.
- **Alternar entre os temas claro e escuro**, conforme sua preferência.
- **Consultar o contraste** entre as cores para avaliar a legibilidade.

## Feito para o processo criativo

O Shade Studio não precisa ser usado apenas para criar interfaces.

Você pode usar os tons para procurar sombras em textos, contornos, ícones, logos, ilustrações, elementos decorativos e degradês no Photoshop ou em qualquer outro editor de imagem.

A proposta é facilitar a busca por cores que conversem entre si, mantendo uma identidade visual consistente sem precisar escolher cada tom do zero.

## Como funciona

Você escolhe uma cor, ajusta a intensidade e recebe oito variações progressivamente mais escuras. Depois, é só comparar, copiar e experimentar no seu projeto.

A escala é gerada automaticamente, então você pode testar outras cores sempre que precisar. O resultado depende da cor original e da intensidade escolhida.

## Simples de usar

O Shade Studio funciona diretamente no navegador, sem precisar instalar programas ou configurar um ambiente de desenvolvimento.

1. Escolha uma cor ou digite um código HEX.
2. Ajuste a intensidade das sombras.
3. Compare os oito tons gerados.
4. Copie as cores que combinarem com seu projeto.

## Tecnologias

O projeto foi desenvolvido com HTML, CSS e JavaScript, sem frameworks.

- [iro.js](https://iro.js.org/) para o seletor de cores.
- Google Fonts para a tipografia.
- `localStorage` para salvar a preferência de tema.

## Projeto independente

O Shade Studio é um projeto criado para tornar uma parte do processo de design mais prática e acessível.

O código fica disponível para consulta, personalização e adaptação. Você pode modificar a ferramenta para experimentar outras progressões de cores e adequá-la ao seu próprio fluxo de trabalho.
